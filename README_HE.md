# נצור לשונך — גרסה מקוונת

זו גרסה אמיתית של המערכת עם שרת ומסד נתונים מרכזי.

## מה כלול
- התחברות לכל אנשי הצוות באימייל וסיסמה.
- תפקידים: מנהל / צוות לימודים / צוות פנימייה.
- מסד נתונים PostgreSQL מרכזי.
- דיווח + / - בלחיצה אחת.
- ההגבלה נאכפת בשרת: לכל תלמיד ניתן פלוס אחד ומינוס אחד בכל שעה עגולה בכל המערכת.
- מנהל יכול ליצור, לערוך, להשבית ולמחוק משתמשי צוות.
- מנהל יכול לשנות אימייל וסיסמה של משתמש צוות.
- מנהל יכול להקצות לכל איש צוות בדיוק את הכיתות / קבוצות הפנימייה שהוא רשאי לראות.
- מנהל יכול להוסיף, לשנות ולמחוק תלמידים.
- מנהל יכול להוסיף, לשנות ולמחוק כיתות וקבוצות פנימייה.
- מנהל יכול לצרף ולהסיר תלמידים מכל קבוצה.
- יומן דיווחים מלא ושם איש הצוות שדיווח.
- סיסמאות מוצפנות עם bcrypt ונשמרות בצד השרת.
- התחברות באמצעות עוגיית HttpOnly, כך שהסיסמה אינה נמצאת בקובץ ה-HTML.

## פריסה מומלצת
הדרך הפשוטה:
1. פותחים PostgreSQL בענן (למשל Render PostgreSQL / Railway / Neon).
2. מעלים את כל התיקייה לשירות Node.js כגון Render או Railway.
3. מגדירים משתני סביבה לפי `.env.example`.
4. מריצים פעם אחת:
   `npm run init-db`
5. מפעילים:
   `npm start`

## משתני סביבה
- `DATABASE_URL` — כתובת מסד הנתונים.
- `JWT_SECRET` — מחרוזת ארוכה ואקראית.
- `ADMIN_EMAIL` — אימייל המנהל הראשון.
- `ADMIN_PASSWORD` — סיסמת המנהל הראשון.
- `NODE_ENV=production`

## הערה חשובה
לא ניתן להפוך קובץ HTML בלבד למערכת מאובטחת ומסונכרנת. הגרסה הזו כוללת שרת אמיתי ומסד נתונים ולכן מי שיש לו רק את הקישור אינו יכול להיכנס בלי משתמש וסיסמה.

## הקצאת כיתות לאנשי צוות
מתבצעת כעת ישירות מתוך מסך המנהל באמצעות סימון הכיתות והקבוצות המותרות לכל משתמש.
