## מה השתנה

2. **סריקת נגישות:** הסריקה קוראת את המסך בלי לשנות אותו. שם כללי כמו „שדה” או „בחירה” אינו נוסף כדי להעלים ממצאים. תוויות ריקות והפניות ARIA חסרות נבדקות בפועל; תמונות בעלות תיאור יכולות לתת שם לכפתור או לקישור.
3. **שמות שדות דינמיים:** השלמת שם נעשית רק מתוך תיאור קיים, כגון כיתוב סמוך מתאים או placeholder תיאורי. שינוי תיאור מעדכן שם אוטומטי; שם שהוגדר במפורש בקוד נשמר. שינויים מרובים מאוחדים לסריקה אחת.
4. **פרטיות של ממצאי נגישות:** דוגמאות הנשמרות בדוח כוללות רק סוג רכיב. הן אינן כוללות HTML מלא, ערכי שדות, מזהים או טקסט שהוקלד.
5. **תאימות דפדפנים:** בדיקת יכולות אוטומטית מוצגת בנפרד מבדיקה ידנית. התווסף טופס לתיעוד בדיקה ידנית עם גרסת דפדפן, מערכת הפעלה, אסמכתה ואישור ביצוע מפורש. בדיקות אוטומטיות בלבד אינן מעלות את ציון התאימות הידנית.
6. **ראיות נגישות:** סימון בדיקה ידנית כעוברת דורש אסמכתה ואישור ביצוע. רשומת בדיקת חובה חסרה מופיעה ברשימת החסמים. טיוטה שלא נשמרה אינה נמחקת כששומרים בדיקה אחרת.
7. **מטריצת התקנים:** לא ניתן לשמור PASS ללא אסמכתה, או למחוק אסמכתה ולהשאיר PASS. רשומות PASS ישנות ללא אסמכתה מוצגות כחלקיות. בדיקת הדפדפנים לבדה אינה מאשרת את תקן התאימות המלא.
8. **שמירת Snapshot:** כל כתיבות הסנכרון נבדקות. כאשר תמונת המצב נשמרה אבל הסנכרון נכשל, המערכת מציגה תוצאה חלקית מפורשת. מנגנון ה-SHA-256 נשאר תואם למניפסט שנשמר.
9. **טעינה ורענון:** מרכז הנגישות ומטריצת התקנים מציגים שגיאה וכפתור ניסיון חוזר. רענון חלקי של הסקירה אינו מוחק נתונים קודמים או מודיע שהכול עודכן. תוצאת Preflight שנכשלה אינה מוצגת כהצלחה; תוצאה קודמת מסומנת בהתאם.
10. **תצוגה בעברית:** יחסי הספירה מוצגים בכיוון מספרי מפורש כדי למנוע היפוך של מונה ומכנה בתוך ממשק RTL.
